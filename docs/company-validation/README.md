## 공통 판정

- `Strong`: 정책 적합성, 사업 직접성, 성장 촉매가 함께 확인된 우선 검토 후보입니다.
- `Watch`: 섹터 관련성은 유효하나 수주, 매출 비중, CAPEX, 재무 체력 중 일부가 불확실한 관찰 후보입니다.
- `Reconsider`: 직접성, 가격 부담, 재무 리스크, 신규자금 명분 중 약점이 커서 후순위 또는 제외 검토가 필요한 후보입니다.

## v2 추가 판정

- `A`: 3000억원 이하이고 `Strong` 또는 `Watch`입니다.
- `C`: 3000억원 이하이나 `Reconsider`입니다. 저시총이라는 이유만으로 최종 후보에 넣지 않습니다.
- `제외`: 3000억원 초과입니다. 다만 `Strong`이거나 3000억~3500억원 경계 후보는 추적군으로 유지합니다.
