## 공통 결론

- `조` 단위 시총은 반드시 억원으로 환산해야 합니다. 예: `1조 892억원`은 `10,892억원`입니다.
- 3000억원 이하라도 `Reconsider` 후보는 자동 편입하면 안 됩니다.
- 3000억~3500억원 후보는 최신 시총 변동으로 편입/제외가 바뀔 수 있어 경계 재확인 대상으로 둡니다.
- 3000억원 초과 `Strong` 후보는 최종 후보에서는 제외하되, 섹터 대표성과 정책 적합성이 높으면 추적군에 남깁니다.

- GST, 하나마이크론, 티에스이 등 `조` 단위 후보는 단순 숫자 파싱 시 오분류됩니다.
