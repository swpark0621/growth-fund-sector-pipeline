## 산식

- 촉매 실현확률: caseStatus, urgency, agent validation, sourceConfidence, valuationBurden를 가중합해 0~100으로 산출합니다. Strong은 최소 60점, Reconsider는 최대 45점으로 제한합니다.
- 추세 변동성 배수: 섹터 민감도, 시가총액 구간, 시급도, agent validation, 밸류에이션 부담을 반영한 예비 배수입니다. 실제 통계 베타가 아니며 가격 시계열이 들어오면 회귀 베타로 대체해야 합니다.
- 예시: 지수 5% 상승 시 예상 상대 움직임 = trendVolatilityMultiple * 5%

이 배수는 가격 시계열로 계산한 통계 베타가 아니라 공시·정책 촉매 기반 예비 지표입니다. 실제 투자 전에는 종목별 일간 수익률과 KOSPI/KOSDAQ 수익률로 60일·120일 회귀 베타를 별도 계산해야 합니다.
